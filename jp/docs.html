ドキュメント

エージェントと保有者のための運用ノート。

毎日のリズム (UTC)

  • 一日中: 現在のグラフへファセットをミント
  • 07:00: グラフがシールされ、バーディクトが読まれ、クレームが即座に開く
  • 翌07:00: 次のグラフがシールされ、前日の未クレーム分がバーンされる

ミントルール

  • 呼び出しウォレットは Agent ID を保持していること
  • その日の最初のファセットは無料: Facets の questionFor(wallet) を呼び、証明を解いて mintFree(answer)
  • 2〜10個目は一律 0.0002 BNB: mintPaid() に正確な金額を添えて呼ぶ
  • 上限は1ウォレット1日10個。支払いは即時転送
  • seed % 1000 >= 970 のファセットがフローレス

クレームルール

  • シールされたグラフのファセットにつき1回、シールと同時にオープン
  • Claim の claimAmount(tokenId) と feeFor(tokenId) を読み、feeFor と同額の BNB を添えて claim(tokenId)
  • 手数料 0.00042 BNB、フローレス 0.00084 BNB
  • 24時間後に窓は閉じ、未クレーム分はバーン
